# 화면 속 "저사람 누구야?"

> 보다가 궁금한 인물·소품·장소를 포인터로 가리키면, 그 정보를 내 손 안에서 확인하는 넷플릭스 TV 경험

멀티모달 인터페이스 디자인 6주차 과제("새로운 넷플릭스 TV 경험 제안")의 웹 프로토타입입니다. 넷플릭스형 홈에서 작품을 고르고, 보다가 화면 속 대상을 휴대폰이나 마우스로 가리키면 영상을 멈추지 않고 정보를 탐색합니다.

| 작품 | 가리켜서 찾을 수 있는 것 | 함께 보여 주는 것 |
|---|---|---|
| **미스터 션샤인** (tvN, 2018 · 공식 하이라이트 14분) | 인물 5명(→ 배우), 소품 6개, 장소 1곳 | OST 15곡, 촬영지 |
| **치이카와** (51~55화) | 캐릭터 5명 → 일본어판 성우 → 공식 프로필 출연작 | 출연작 공식 클립 |

"성우 정보만 찾는 데 쓰기엔 아쉽다"는 피드백을 받아, 미스터 션샤인으로 인물·소품·장소·음악까지 넓혔습니다.

넷플릭스의 홈·상세·재생 흐름을 참고한 자체 UI(NUTFLIX)이며, 넷플릭스 계정이나 서비스와는 연결되지 않습니다.

> **영상 공개 기한 주의**: 치이카와 영상(めざましテレビ 공식 채널의 「ちいかわ」 51~55화)은 **2026년 11월 6일(금) 오전 7:59까지 1주간 한정 공개**입니다. 그 뒤에는 YouTube에서 재생되지 않으므로, 시연 장면은 미리 녹화해 두세요. 영상을 바꾸려면 [7. 영상 바꾸기](#7-영상-바꾸기)를 보세요.

## 1. 제안하는 경험

**사용 상황.** 사용자는 가족·친구와 함께 애니메이션을 보다가, 화면 속 캐릭터와 그 목소리의 주인을 바로 알고 싶어 합니다. 하지만 지금은 재생을 멈추거나 휴대폰으로 따로 검색해야 해서 시청 흐름이 끊기고, 함께 보는 사람의 시청까지 방해됩니다.

**새로운 경험.** 시청 중 화면 속 캐릭터가 궁금할 때, 휴대폰으로 TV 화면 속 대상을 직접 가리키는 포인팅 방식의 원거리 인터랙션을 통해, 재생을 멈추지 않고 다른 사람의 화면을 가리지 않은 채 그 정보를 내 리모컨에서 바로 확인합니다.

**입력 방식: 혼합형.** 화면 속 캐릭터는 메뉴처럼 격자 위에 있지 않아 방향키로는 갈 경로가 없습니다. 그래서 위치를 직접 지정하는 포인팅을 중심에 두었습니다.

| 입력 | 역할 |
|---|---|
| 포인팅 | 영상 속 캐릭터 직접 선택 (핵심) |
| 터치패드 | 홈·상세·정보 카드까지 화면 전체 포인터 이동 |
| 기울기 센서 | 휴대폰을 기울여 포인터 조준 (HTTPS 필요) |

**TV와 휴대폰의 역할 분담.** 두 화면은 같은 정보를 반복하지 않습니다.

| TV 화면 · 함께 보는 정보 | 휴대폰 · 개인 조작과 정보 |
|---|---|
| 영상은 멈추지 않고 계속 재생 | 캐릭터 → 성우 → 출연작 상세 탐색 |
| 가리킨 캐릭터에 Hover 외곽선과 이름 표시 | 내가 찾은 캐릭터의 검색 기록 (최근 8명) |
| 터치패드를 쓰는 동안만 작은 원형 포인터(2초 쉬면 사라짐), 캐릭터 위에서 얇은 링 | 선택하면 아래에서 미리보기 시트(썸네일·이름·작품·성우) |
| 선택하면 그 자리에 0.8초 체크·원 확산, 영상은 멈추지 않음 | 시트를 위로 밀거나 "자세히 보기" → 상세, 뒤로 가면 시트로 복귀 |
| 큰 정보 창으로 화면을 가리지 않음 | 터치패드·센서와 큰 재생/일시정지 버튼 |

휴대폰 없이 PC 마우스로만 쓸 때는 TV 오른쪽의 유리 정보 패널에서 같은 탐색을 할 수 있습니다.

## 2. 실행 방법

Node.js 22 이상이 필요하고, 영상과 글꼴을 온라인에서 불러오므로 인터넷 연결이 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. Windows는 `Start.bat`, macOS는 `Start.command`를 더블클릭해도 됩니다(처음 한 번 `npm install`을 자동으로 실행합니다).

| 명령 | 용도 |
|---|---|
| `npm run dev` | 개발 서버 (Vite 포함) |
| `npm run build` 후 `npm start` | 빌드한 배포 모드로 실행 |
| `npm test` | 판정 로직 테스트 |
| `npm run test:integration` | 실제 서버를 띄우는 통합 테스트 |

포트는 `PORT` 환경변수로 바꿀 수 있습니다.

### 휴대폰 연결

1. PC와 휴대폰을 같은 Wi-Fi에 연결합니다. PC 방화벽에서 서버 포트(기본 5173)를 허용합니다.
2. 화면 오른쪽 위 **리모컨 연결**을 눌러 QR을 스캔합니다. QR 주소가 PC의 LAN 주소인지 확인하고, VPN 주소가 잡히면 주소 칸을 고칩니다. Wi-Fi 주소가 바뀌면 10초 안에 QR이 자동 갱신됩니다.
3. **터치패드**는 일반 HTTP 주소에서도 동작합니다.
4. **기울기 센서**는 휴대폰 보안 정책상 HTTPS 주소에서만 켜집니다. 아래 HTTPS 설정을 참고하세요. 휴대폰을 세로로 잡고 센서를 켠 뒤 기준점을 맞추고, 좌우 회전·상하 기울기로 포인터를 움직여 터치패드를 한 번 탭해 선택합니다.

연결은 세션 토큰으로 확인하며, 서버를 다시 켜면 QR을 다시 스캔해야 합니다. 링크를 가진 사람은 그 세션을 조작할 수 있으니 시연 참가자에게만 보여 주세요.

### HTTPS 설정 (센서를 쓸 때)

mkcert 같은 개발 인증서 도구로 PC의 실제 LAN IP가 포함된 인증서를 만듭니다.

```sh
mkdir -p .cert
mkcert -install
mkcert -key-file .cert/key.pem -cert-file .cert/cert.pem localhost 127.0.0.1 192.168.0.10
TLS_KEY=.cert/key.pem TLS_CERT=.cert/cert.pem npm run dev
```

`192.168.0.10`은 PC의 LAN IP로 바꾸고, 휴대폰에도 로컬 CA 인증서를 설치해 신뢰로 설정합니다(iOS는 설정 → 인증서 신뢰 설정). 개인키는 공유하거나 커밋하지 마세요. 대안으로 5173 포트에 HTTPS 터널을 연결하고, PC·휴대폰 모두 그 주소를 쓰도록 QR 주소를 고쳐도 됩니다.

## 3. 사용 방법

**추천 시연 순서**: 홈(미스터 션샤인) → 재생 → 0:15 유진 초이(모자를 가리키면 장교 군모) → 배우 이병헌 → 2:53 장총 → 6:28 호텔 글로리 → 상세 정보의 OST·촬영지 → 홈에서 치이카와로 바꿔 5초 치이카와 → 일본어판 성우 → 공식 프로필 출연작.

1. 영상을 재생하고 궁금한 캐릭터 위로 포인터를 옮깁니다. 등록된 캐릭터 위에서는 외곽선과 이름이 나타납니다.
2. 클릭(휴대폰은 한 번 탭)하면 선택됩니다. 영상은 멈추지 않습니다.
3. 캐릭터 정보 → 담당 성우(일본어판) → 소속사 공식 프로필의 다른 출연작 순서로 탐색합니다. 출연작을 누르면 그 애니메이션의 상세 화면이 열리고 공식 클립이 재생됩니다(치이카와 영상은 소리가 겹치지 않도록 일시정지). 상세 화면 아래 "○○의 다른 출연작"에서 같은 성우의 다른 애니로 바로 넘어갈 수 있습니다.
4. 캐릭터가 없는 곳을 누르면 검색 창 대신 "앗, 캐릭터가 선택되지 않았어요" 안내가 나옵니다. 패널이 열려 있을 때는 패널만 닫힙니다.
5. 아래쪽 **캐릭터** 버튼으로 이름·성우를 직접 검색할 수 있습니다.

**키보드**: Space 재생/일시정지 · F 앱 전체화면 · M 음소거 · Esc 패널·모달·전체화면 닫기. 영상 선택 영역에 포커스를 두면 방향키로 포인터를 옮기고 Enter로 선택합니다.

**휴대폰 터치패드**: 한 손가락으로 밀어 이동, 350ms 안의 짧은 탭으로 클릭, 두 손가락으로 스크롤. 포인터 속도와 터치패드·센서 전환은 리모컨 오른쪽 위 설정 버튼에 있습니다. 터치패드 아래에는 TV의 재생 상태를 따라 아이콘이 바뀌는 재생/일시정지 버튼 하나만 두었고, 그 아래 **검색 기록**에 휴대폰에서 찾은 캐릭터가 최근 순으로 쌓입니다(휴대폰 브라우저에 저장, 누르면 다시 열림, "지우기"로 비움).

## 4. 화면과 기능

### 홈
- 대표 작품(미스터 션샤인) 빌보드: 재생·이어서 재생, 상세 정보
- **NUTFLIX에서 탐색할 수 있는 작품**: 미스터 션샤인, 치이카와. 카드를 누르면 상세, 재생 아이콘을 누르면 바로 재생
- **화면 속 인물**, **소품과 장소**, **OST** 줄(미스터 션샤인)과 **목소리의 주인공** 줄(치이카와 일본어판 성우)
- 찜한 콘텐츠(작품별)와 작품별 이어보기 위치는 이 브라우저에 저장됩니다.

### 작품 상세
- 작품마다: 재생, 찜하기, 장르·방송 정보, 출연, 영상, "이 작품에서 찾을 수 있는 것"(인물·소품·장소 또는 캐릭터)
- 미스터 션샤인은 아래에 **음악 · OST**(15곡, 누르면 YouTube 검색)와 **촬영지**(지도·출처 링크)가 이어집니다.

### 플레이어
- 상단: 홈으로, 작품·화 제목, 작품 정보
- 하단: 시간 이동, 재생, 10초 이동, 음량, 캐릭터, 휴대폰 연결, 밝기, 전체화면
- 컨트롤은 3초간 조작이 없으면 숨고 포인터를 움직이면 다시 나타납니다.
- 음량(0~100%)은 YouTube 플레이어에, 밝기(40~150%)는 영상 레이어에만 적용되며 브라우저에 저장됩니다.

### 정보 패널
- 종류마다 다르게 보여 줍니다. **인물** → 배우(위키백과 링크)와 그 인물과 이어진 소품, **소품·장소** → 등장 시점·관련 인물·촬영 정보와 출처, **캐릭터**(치이카와) → 아래 성우 단계.
- 캐릭터 → 성우: 성우 사진, 이름, 소속사, 공식 프로필의 다른 출연작(작품명·배역을 프로필 표기 그대로, 8개 이후는 "모두 보기"), 공식 프로필 링크
- 출연작 → 작품 상세: 공식 클립(캐릭터 PV 또는 작품 공식 PV), 작품 소개(일본어 위키백과 첫 문단을 한국어로 옮긴 글과 출처 링크), 배역·성우, 같은 성우의 다른 출연작 목록(누르면 그 작품 상세로 이동)
- 오른쪽 유리 패널(반투명 배경 + backdrop-filter). 접기·펼치기를 지원하고, 투명도 줄이기 설정이나 미지원 환경에서는 불투명 배경으로 바뀝니다.
- X, Esc, 패널 바깥 클릭으로 닫힙니다.
- 휴대폰으로 선택한 경우에는 TV에 0.8초 체크 애니메이션만 나오고, 휴대폰 아래에 미리보기 시트(화면의 약 28%)가 올라옵니다. 시트 위의 터치패드는 계속 쓸 수 있고, 다른 캐릭터를 고르면 같은 시트 내용만 바뀝니다. 시트에서 위로 밀기(또는 "자세히 보기")는 상세 화면, 아래로 밀기(또는 X)는 닫기입니다. 상세 화면에서는 터치패드가 숨고, "터치패드로 돌아가기"나 휴대폰 뒤로 가기로 직전 캐릭터의 시트가 열린 터치패드로 돌아옵니다.

### 엔딩
- 엔딩(치이카와 305초, 미스터 션샤인 834초)이 시작되면 오른쪽 아래에 **크레딧 보기**와 **상세 정보** 버튼이 나타나고, 재생 중이면 5초 카운트다운 뒤 영상을 멈추고 그 작품의 상세를 엽니다. 일시정지하면 카운트다운도 멈춥니다.

### 장면 편집 (캐릭터 영역 추가)
플레이어에서 장면 편집을 열고 영상 위에 드래그해 영역을 그립니다. 캐릭터와 시간을 정하고, 이동하는 장면은 키프레임을 추가한 뒤 서버에 저장합니다. JSON 가져오기·내보내기로 백업할 수 있고, 검증에 실패한 데이터는 저장하지 않습니다.

### 출연작 상세: 공식 클립과 작품 소개

출연작 61개 각각에 대해 `src/workInfo.ts`에 공식 클립과 작품 소개를 넣었습니다.

- **클립 50개**: YouTube에서 「작품명 + 배역명」과 「작품명 PV」로 찾은 결과 중, 제작사·배급사·방송사·작품 공식 채널(KADOKAWAanime, 아니플렉스, MAPPA, 도호 등) 영상만 썼습니다. 개인 업로드·반응 채널·자동 생성 음악 채널은 제외했습니다.
  - **캐릭터 PV 11개**: 영상 제목에 배역 이름이 들어간 공식 영상(캐릭터 PV, 캐릭터 소개, 캐릭터 송 등)
  - **작품 공식 PV 39개**: 배역 전용 영상이 없어 작품 전체 PV를 넣은 경우. 화면에 "이 배역이 나오지 않거나 잠깐만 나올 수 있어요"라고 안내합니다.
  - 모든 클립은 삽입 재생이 허용되는지 확인했습니다.
  - 클립이 없는 11개는 공식 채널 영상을 찾지 못한 작품이며, YouTube 검색 링크를 대신 보여 줍니다. 「クレヨンしんちゃん」은 찾은 영상이 배역과 무관한 극장판 광고라 넣지 않았습니다.
- **작품 소개 41개**: 일본어 위키백과에서 작품명으로 찾은 문서의 첫 문단을 한국어로 옮긴 글과 원문 링크. 제목이 맞지 않는 문서는 제외했고, 찾지 못한 작품은 "자료를 찾지 못했어요"라고 표시합니다.

### 영역 117개 (치이카와 101 · 미스터 션샤인 16)

- 영역마다 어느 영상의 것인지(`video`)가 들어 있고, 재생 중인 영상의 영역만 선택됩니다.

- 치이카와는 YouTube 스토리보드(5초 간격 축소 프레임, 320×180)를 사람이 보고 표시했습니다. 각 영역은 해당 프레임 앞뒤 2초 구간이며, 기록은 `data/timeline-review.json`에 있습니다.

## 6. 기술 구성

```
TV 화면 (PC 브라우저)  ⇄  서버 (Express + Socket.IO)  ⇄  스마트폰 리모컨 (웹)
YouTube IFrame API        세션 토큰 · 재생 시점 기준 영역 판정     터치패드 · 기울기 센서 · 진동
```

- **화면**: React 19, TypeScript, Vite, Tailwind CSS
- **서버**: Express, Socket.IO, QR Code. 세션은 메모리에, 캐릭터 영역은 JSON 파일에 저장합니다. HTTPS와 Socket.IO는 같은 서버·포트를 씁니다.
- **선택 판정**: `src/logic.js`의 같은 로직을 서버와 화면이 함께 써서 마우스와 휴대폰이 같은 결과를 냅니다.
- **센서**: 기준점 대비 상대 회전을 포인터로 바꾸며, 0.2 평활화와 약 30Hz 전송을 적용합니다. TV를 향한 절대 조준이나 영상 AI 분석은 구현하지 않았습니다.

| 파일 | 내용 |
|---|---|
| `server.mjs` | 서버, 세션, 영역 판정, 리모컨 입력 중계 |
| `src/main.tsx` | 플레이어, 정보 패널, 리모컨 화면, 장면 편집 |
| `src/BrowseHome.tsx` | 홈, 작품 상세, OST·촬영지(`TitleExtras`) |
| `src/data.ts` | 작품(`titles`), 인물·소품·장소·캐릭터(`characters`), 성우·배우(`actors`) |
| `src/workInfo.ts` | 출연작별 공식 클립, 한국어 제목·배역·소개(`ko`) (조사 결과로 생성) |
| `src/WorkClip.tsx` | 출연작 상세 화면 (클립, 소개, 같은 성우의 다른 출연작) |
| `src/logic.js` | 영상 ID(`VIDEOS`), 영상별 영역 활성화·보간·선택 판정·데이터 검증 |
| `data/regions.json` | 영역 117개 (영상별) |

## 7. 영상 바꾸기

영상 공개가 끝났거나 다른 화로 바꾸려면:

1. `src/logic.js`의 `VIDEOS`에서 해당 작품의 영상 ID를 바꿉니다.
2. `src/data.ts`의 `titles`(제목, 길이, 엔딩 시작 초 `credits`, 출처)를 고칩니다.
3. 새 영상에 맞게 `data/regions.json`에서 그 영상의 영역을 다시 만듭니다(장면 편집기 사용 가능, `video` 값 포함). 등장 대상이 바뀌면 `characters`, `actors`, `logic.js`의 `characterIds`도 함께 고칩니다.
4. `logic.test.mjs`, `integration.test.mjs`의 시점·좌표를 새 영상에 맞추고 `npm test`, `npm run test:integration`, `npm run build`를 통과시킵니다.

자세한 검증 기록은 [TEST_RESULTS.md](TEST_RESULTS.md)에 있습니다.

**검증한 것**
- 자동 테스트 16개 통과 (판정 로직 10 · 실제 서버 통합 6)
- 미스터 션샤인: 홈·상세(OST·촬영지), 0:15 포인팅 → 유진 초이 → 배우 → 장교 군모, 호텔 글로리 패널, 휴대폰 시트("배우 김태리", "장소 · 미스터 션샤인")를 브라우저에서 확인
- 홈에서 치이카와로 바꾸면 치이카와 영상이 재생되고 치이카와 영역만 선택됨
- TypeScript 검사와 프로덕션 빌드 통과
- 새 영상 재생, 캐릭터 선택 → 일본어판 성우 → 공식 프로필 출연작, 홈 성우 선반, 엔딩 카드를 브라우저에서 확인
- 출연작 상세에서 공식 클립 재생(月刊少女野崎くん), 같은 성우의 다른 출연작으로 이동(がっこうぐらし！, えとたま)

**한계**
- 치이카와 영상은 2026년 11월 6일 오전 7:59 이후 재생되지 않습니다(미스터 션샤인은 상시 공개된 공식 영상).
- 미스터 션샤인 인물은 배우 이름이 화면에 나오는 소개 장면에서만 선택됩니다. 소품·장소도 표시한 16개 구간 밖에서는 선택되지 않습니다.
- OST는 작품 전체 목록이며, 지금 장면에서 흐르는 곡을 알려 주지는 않습니다.
- 실제 스마트폰의 QR 접속, HTTPS 인증서 신뢰, 기울기 센서, 진동, 기종별 센서 축은 검증하지 않았습니다.
- 캐릭터 영역은 5초 간격 프레임을 보고 수동 표시한 값이라 어긋나는 구간이 있습니다.
- 성우 출연작은 공식 프로필에 실린 범위만 보여 주며, 프로필이 "他多数"로 줄인 작품은 포함되지 않습니다.
- 출연작 클립의 대부분(39개)은 작품 전체 PV라 해당 배역이 나온다고 보장할 수 없습니다. 공식 영상은 이후 비공개로 바뀔 수 있습니다.
- 작품 제목·배역·소개는 한국어로 표시하고, 공식 프로필의 일본어 표기는 '원제'와 괄호로 함께 보여 줍니다. 한국 정식 제목이 없는 작품과 배역 이름은 음역이라 실제 한국판 표기와 다를 수 있고, 소개 번역은 사람이 원문과 대조하지 않았습니다.
- YouTube 재생 허용 여부, 광고, 지역 제한, 네트워크 상태에 따라 재생이 달라질 수 있습니다. 영상 다운로드·스트림 추출·DRM 우회는 사용하지 않았습니다.
